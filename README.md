## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

To rebuild `entry.png` from source (`src/news-data.ts`, `src/world-map.ts`, `src/template.ts`, `src/render.py`):

```sh
node src/build-html.ts
python src/render.py
```
